# Tool identification marks

Runquay serves these small SVG assets locally to identify the selected tool on session, task and account cards. Labels remain visible for accessibility and clarity. No remote icon requests are made while using the dashboard. The marks identify their respective products; they do not indicate endorsement or partnership. Runquay's own brand remains separate.

| Local file | Source | Notes |
| --- | --- | --- |
| `web/tool-icons/codex.svg` | [OpenAI favicon](https://openai.com/favicon.svg), linked by the [official brand page](https://openai.com/brand/) | Unmodified OpenAI Blossom mark used beside the Codex label. OpenAI retains its trademark rights. |
| `web/tool-icons/claude.svg` | [Simple Icons Claude path](https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg) | CC0 SVG path, rendered in Claude's terracotta color. Anthropic retains trademark rights. |
| `web/tool-icons/gemini.svg` | [Simple Icons Google Gemini path](https://github.com/simple-icons/simple-icons/blob/develop/icons/googlegemini.svg) | CC0 SVG path, rendered in a light blue for the dark interface. Google retains trademark rights. |
| `web/tool-icons/antigravity.svg` | [Official Antigravity press assets](https://antigravity.google/press), full-color icon | Unmodified SVG from Google's press assets; Google retains trademark rights. |
| `web/tool-icons/custom.svg` | Runquay | Generic terminal symbol for custom tools and imported labels without a known native provider. It does not impersonate another vendor. |

Simple Icons distributes its icons under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md); that dedication does not grant trademark rights. Assets are selected from a fixed local route allowlist. Imported tool names cannot supply icon URLs or trigger third-party tracking requests.
