How your work becomes learnings

Runquay automatically finds matching summaries from local Codex, Claude, Gemini, Antigravity and imported histories, plus completed Runquay reports. Topic suggestions are local matches, not AI conclusions. Full conversations and raw logs are not read.

You see the chosen context before it goes to an AI. Analysis uses your provider allowance and existing billing approvals. No purchases or resets happen automatically. Only this analysis starts; other paused tasks stay paused. AI drafts are stored locally, with source references and caveats. Choose Keep or Use in a task when a lesson is useful.

Source removal and credential/email/path filtering are best effort. Private project details can remain, so check the preview. Codex, Claude and Gemini support analysis; other tools can contribute history. Lessons are advice, not verified facts. Nothing is published or written into another tool’s memory automatically.

About accounts and usage

There is no account-count cap. Each separate account needs its own vendor sign-in. Adding profiles does not increase allowance. Codex can move to another eligible Codex account; other tools ask before each run. Credentials stay with the vendor tool. Removing a connection keeps its credentials and history.

    Allow one AI run?
    Runquay cannot verify this tool’s quota, authentication billing mode, or paid balance. Check the vendor’s account and billing settings first. This approval permits one invocation and any vendor charges it may incur. No credits or resets are purchased by Runquay.
    

    Import task history
    Claude Code, Gemini and available Antigravity transcripts are detected automatically. For another tool, choose a Runquay-compatible history JSON export. Only task metadata is saved on this computer; nothing is sent to an AI provider.
    Up to 100 tasks per file, below 60 KB. This does not import credentials or start work.
    Supported export format
    {"version":1,"tool":"Your AI tool","tasks":[{"id":"task-1","title":"Improve my website","preview":"Optional short summary"}]}
    Optional cwd must be an absolute folder path. Optional updated_at accepts an ISO date or Unix timestamp. Other fields are ignored. Raw vendor transcripts need a converter to this metadata format.
