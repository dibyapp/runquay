Where learnings come from and how they are used

Sources are bounded, locally detected chat titles/previews and completed Runquay step reports. Full native conversations, raw logs and cloud-only chats are not analyzed. Imported metadata can add summaries from other tools. An analysis includes at most 100 sources and 120,000 characters.

Codex, Claude Code and Gemini currently have read-only analysis adapters. Antigravity and custom adapters can supply history; analysis through them waits for a supported read-only adapter. Learnings stay in your private Runquay data folder. The AI receives only the reviewed snapshot through its CLI. Credential, email and path removal is best effort; review the preview for private project details.

AI lessons may be wrong, stale or based on incomplete evidence. Edit or dismiss them, then save the useful ones. When adding a task, choose up to 12 saved learnings; only those lesson texts are copied into the task, without source summaries. They are reference material and cannot authorize actions. Nothing is published or added to another tool’s instructions automatically.

About accounts and usage

There is no account-count cap. Each separate account needs its own vendor sign-in. Adding profiles does not increase allowance.     Import task history
    Claude Code, Gemini and available Antigravity transcripts are detected automatically. For another tool, choose a Runquay-compatible history JSON export. Only task metadata is saved on this computer; nothing is sent to an AI provider.
    Up to 100 tasks per file, below 60 KB. This does not import credentials or start work.
    Supported export format
    {"version":1,"tool":"Your AI tool","tasks":[{"id":"task-1","title":"Improve my website","preview":"Optional short summary"}]}
    Optional cwd must be an absolute folder path. Optional updated_at accepts an ISO date or Unix timestamp. Other fields are ignored. Raw vendor transcripts need a converter to this metadata format.
