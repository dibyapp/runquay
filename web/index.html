Review before you begin
  • Runs stay on this device; selected provider CLIs send prompts and relevant files to their services.
  • Codex requires verified subscription quota and a zero paid balance. Quota checks are polling, not an atomic spending guarantee.
  • Other tools have no verified billing guard: approve each invocation only after checking the vendor account. Possible vendor charges are your responsibility.
  • Earned resets require approval. Runquay never purchases credits, resets, or subscriptions.
  • CLI permissions vary. Review projects and tool settings; the local dashboard is not a universal security sandbox.
  • There is no telemetry. Logs, accounts, projects, and personal configuration stay out of the release bundle.
